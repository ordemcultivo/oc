# O.C - Ordem e Cultivo | Site de pré-lançamento

Site estático de uma página para apresentar a O.C e captar interessados no pré-lançamento.

## Como abrir

Abra `index.html` no navegador.

## Cadastro

O formulário valida os campos e salva os leads em `localStorage` quando não há backend configurado.
Para integrar com um endpoint real, edite `script.js` e preencha `LEAD_ENDPOINT` com a URL de recebimento.

## Arquivos

- `index.html`: estrutura da página
- `styles.css`: visual responsivo
- `script.js`: animação de fundo e formulário
- `assets/logooc_ia.jpg`: logo/imagem de marca
